# Pulmonary–Renal Syndrome: teaching session

A 50-slide interactive HTML presentation for the Respiratory Department, Calderdale Royal Hospital. It runs for about 55 minutes plus questions, and has a 45-minute mode.

Open `index.html` in Chrome or Edge. Everything is in that one file. Fonts load from Google Fonts when you're online; without internet, the slides fall back to system fonts.

## Before the talk
- Click the presenter, supervisor and date fields on the title slide and type your details.
- Fill in the local contacts on the "Who to call" slide.
- Swap in a real feedback QR code on the last slide.

## Presenting
| Key | Action |
| --- | --- |
| → / Space | Next step or slide |
| ← | Back |
| P | Presenter window (notes, timer, next slide) |
| N | Notes drawer |
| S | 45-minute mode (skips the slides marked optional) |
| O | Slide overview |
| B | Black screen |
| L | Light theme for bright rooms |
| F | Full screen |
| R (twice) | Reset team scores |
| ? | Help |
